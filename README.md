#のみログ サポートページ

**のみログ** は、日々の飲酒量を簡単に記録・分析できるiPhoneアプリです。  
このページでは、使い方やサポート情報をまとめています。

---

## 📱 使い方
1. 「クイック追加」で飲んだ量を記録  
2. 「カレンダー」で過去の記録を確認  
3. 「統計」で飲酒傾向をグラフ化  

---

## ⚙️ よくある質問
- **データはどこに保存されますか？**  
　→ 端末内にのみ保存されます。外部サーバーには送信されません。  
- **健康管理に使えますか？**  
　→ 医療目的ではなく、自己記録・意識改善用です。
